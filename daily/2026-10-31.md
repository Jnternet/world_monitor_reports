3. **无地缘事件库**：ACLED / UCDP 无 API key，返回空数组而非报错——埃塞空袭"≥15 死"只有 Reuters 消息源口径，不是核实的事件计数。
4. **自然事件不可用**：`natural.json` 为 `dataAvailable=false`、`events=0`（`GDACS_TYPE_COVERAGE_INCOMPLETE`）。本报告不含气旋/地震/洪水数据；希腊中部与土耳其西部的暴雨洪水警报只有新闻条目（Guardian 10-30 18:07，score 37）。
5. **数据源健康 `UNHEALTHY`**：338 源中 ok 89 / warn 73 / containedWarn 37 / onDemandWarn 36 / **crit 140**；问题项 249（EMPTY 136、STALE_SEED 70、EMPTY_ON_DEMAND 36、EMPTY_DATA 4、COVERAGE_PARTIAL 2、SEED_ERROR 1）；141 个源完全空数据，包括 earthquakes、outages、cyberThreats、unrestEvents、predictionMarkets、cryptoQuotes、flightDelays、sanctionsPressure 等。多数为种子过期（seedAge 约 22–67 小时）。
